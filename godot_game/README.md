# CHERNARUS TALES — Godot mobile prototype

This is a starter Godot 4 project for the mobile story concept.

## Import on Android
1. Download this folder from GitHub as a ZIP (repository root: `godot_game`).
2. Extract the ZIP using your file manager.
3. In Godot Editor, choose **Import** and select `godot_game/project.godot`.
4. Import and run the project.

## Prototype features
- Dark green terminal-style interface inspired by the CHERNARUS TALES archive site.
- Opening/closing the found laptop.
- Diary entry.
- Radio transmission revealed after tuning.
- Stash clue that can be added to the journal.

This prototype uses text-only placeholder presentation. Add your own licensed or original background art and audio later.
